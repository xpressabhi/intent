# Intent project records

This directory is the source of truth for this repository's Intent configuration, engineering context, decisions, and change evidence.

- [AGENT_GUIDE.md](AGENT_GUIDE.md) defines the lightweight adaptive workflow and its completion evidence.
- [PROJECT.md](PROJECT.md) makes repository purpose, architecture, constraints, checks, and conventions discoverable.
- [decisions/](decisions/README.md) contains rationale that remains relevant across changes.
- [changes/TEMPLATE/](changes/TEMPLATE/) provides concise change, conformance, and optional approval records.
- [scripts/verify-change.sh](scripts/verify-change.sh) checks a change against its declarations and runs repository checks.
- [scripts/verify-records.sh](scripts/verify-records.sh) fails a change range that needs a record and has none.
- [protocol/v2.md](protocol/v2.md) and [schemas/v2/](schemas/v2/) define the versioned contract.
